# shine_aura
O **SHINE AURA** é uma plataforma digital inclusiva sobre beleza, moda, autoestima e representatividade. Seu objetivo é oferecer conteúdos, dicas e recomendações específicas para mulheres negras, mulheres trans e pessoas da diversidade, promovendo informação, autocuidado, inclusão e valorização da identidade de forma acessível e acolhedora.
