# Shine✧Aura - Site HTML/CSS/JavaScript

## 🎨 Estrutura do Projeto

```
public-html/
├── index.html              # Página inicial
├── css/
│   └── styles.css          # Todos os estilos CSS
├── js/
│   ├── data.js            # Dados dos posts e categorias
│   ├── main.js            # JavaScript da home
│   └── blog.js            # JavaScript do blog (filtros, busca)
├── images/
│   └── minha_imagem.png   # Imagem personalizada
└── pages/
    ├── blog.html          # Página do blog
    ├── sobre.html         # Página sobre
    └── contato.html       # Página de contato

```

## 🚀 Como Usar

1. **Abrir o site:**
   - Abra o arquivo `index.html` em qualquer navegador moderno
   - Ou use um servidor local (ex: Live Server no VSCode)

2. **Navegação:**
   - Menu superior para navegar entre páginas
   - Categorias clicáveis na home
   - Sistema de filtros e busca no blog

## ✨ Funcionalidades

- **Home:** Hero section, categorias, posts em destaque e últimos posts
- **Blog:** Filtros por categoria, busca em tempo real, grid responsivo
- **Sobre:** História e missão do Shine✧Aura
- **Contato:** Formulário de contato funcional
- **Responsivo:** Funciona perfeitamente em desktop, tablet e mobile
- **Animações:** Animações suaves com CSS e JavaScript vanilla

## 🎯 Características Técnicas

- **100% Vanilla:** Sem frameworks (React, Vue, etc)
- **CSS Puro:** Sem Tailwind ou Bootstrap
- **JavaScript ES6+:** Código moderno e limpo
- **Mobile First:** Design responsivo
- **Performance:** Otimizado para carregamento rápido

## 📱 Compatibilidade
